# Mushroom Growing Control System

## Overview
The Mushroom Growing Control System is an IoT-based solution designed to monitor and control environmental conditions required for healthy mushroom cultivation. The system helps maintain optimal temperature, humidity, and lighting levels automatically.
## Site is live at
https://wcdeshapriya.github.io/Mushroom-Growing-Control-System/

## Features
- Real-time temperature and humidity monitoring
- Automatic environmental control
- Sensor-based environmental monitoring
- Alerts for abnormal conditions
- Improved mushroom growth efficiency

## Components
- Arduino/ESP32 Microcontroller
- Temperature and Humidity Sensor (DHT11/DHT22)
- Relay Module
- Humidifier
- Ventilation Fan
- Light Control System

## Objectives
- Maintain ideal growing conditions for mushrooms
- Reduce manual monitoring and intervention
- Increase productivity and crop quality

## Future Improvements
- Mobile application integration
- Cloud-based data storage
- AI-based growth prediction and optimization
